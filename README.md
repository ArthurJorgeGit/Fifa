# Fifa - CRUD de Jogadores

Projeto simples em Java para praticar lógica de programação,
orientação a objetos e manipulação de listas (CRUD via console).

## Funcionalidades
- Cadastrar jogador
- Listar jogadores
- Buscar jogador por nome
- Atualizar dados do jogador
- Remover jogador

## Tecnologias
- Java

## Como rodar
Clone o repositório e execute a classe `Program.java`.
